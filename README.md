# Hand Danger Zone Detection

This project detects whether a human hand enters a dangerous zone near industrial machinery using classical image processing in MATLAB.

## Features
- Skin detection using YCbCr and HSV
- Morphological filtering
- Hand detection using region analysis
- Danger zone overlap detection

## Output
- SAFE
- HAND IN DANGER ZONE

## How to Run
1. Open MATLAB
2. Place images in working directory
3. Run `classicalmatlab.m`
